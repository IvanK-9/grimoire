# R-001: Offline first

**Phase:** 1 · **Priority:** Must · **Status:** Draft

## User story
As the Storyteller, I want the app to work fully without a network connection so that I can run games anywhere.

## Acceptance criteria
- [ ] Every Phase 1–3 feature works in airplane mode.
- [ ] All character data, scripts and artwork are bundled with the app or stored on the device.
- [ ] The app does not need an account or sign-in.

## Notes / open questions
- Only script fetching (R-011) may use the network, and it is optional.
