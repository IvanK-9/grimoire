# R-006: Reminder tokens

**Phase:** 2 · **Priority:** Must · **Status:** Draft

## User story
As the Storyteller, I want to put reminder tokens on seats so that I can track poison, drunkenness, protection and other ability effects.

## Acceptance criteria
- [ ] Only the reminder tokens of characters in play are offered first. All tokens on the script are available too.
- [ ] A seat can hold several reminder tokens.
- [ ] Tokens can be added, moved to another seat and removed.
- [ ] Generic tokens are available (e.g. "Good", "Evil", custom text).
