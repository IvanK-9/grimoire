# R-004: Minimal grimoire board

**Phase:** 1 · **Priority:** Must · **Status:** Draft

## User story
As the Storyteller, I want to see every seat with its character and state on one phone screen so that I can run the game at a glance.

## Acceptance criteria
- [ ] Seats are shown in table order, readable on a phone in portrait orientation for up to 15 players (+ Travellers).
- [ ] Each seat shows the player name, character and team.
- [ ] One tap toggles alive/dead.
- [ ] A dead player's ghost vote can be marked as used.
- [ ] The Storyteller can change a seat's character to any character, including one not on the script, e.g. after a Snake Charmer or Pit-Hag. If it's off-script, the app highlights it.
- [ ] Every state (alive/dead, ghost vote, character, team) can be set back at any time, e.g. to fix a mistake.
- [ ] The Storyteller can reorder seats and rename players.
- [ ] Each seat can show its character's ability text.

## Notes / open questions
- Layout: a circle, an oval or a list? Circles get cramped with 15+ seats in portrait. Prototype both options.
- Day/night counter in Phase 1?
