# R-007: Character artwork

**Phase:** 2 · **Priority:** Should · **Status:** Draft

## User story
As the Storyteller, I want to see the official character artwork so that I can recognise characters quickly.

## Acceptance criteria
- [ ] Every bundled character has its official icon.
- [ ] The icons are bundled for offline use.
- [ ] Custom characters without artwork fall back to a placeholder.
