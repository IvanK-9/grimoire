# R-012: Night order guide

**Phase:** Later · **Priority:** Could · **Status:** Draft

## User story
As the Storyteller, I want a step-by-step night order for the characters in play so that I don't forget to wake anyone.

## Acceptance criteria
- [ ] Separate lists for the first night and for other nights, limited to the characters in play.
- [ ] Each step shows the seat and player, a reminder of what to do, and whether that player is dead.
- [ ] Steps can be ticked off in any order, skipped or reordered. The guide suggests; it never forces the order.
- [ ] The Storyteller can add any character to tonight's list, even one that isn't in play (e.g. the Drunk's apparent character, or a house-rule step).
