# R-002: Default scripts

**Phase:** 1 · **Priority:** Must · **Status:** Draft

## User story
As the Storyteller, I want the base scripts available out of the box so that I can start a game without preparing anything.

## Acceptance criteria
- [ ] Trouble Brewing, Bad Moon Rising and Sects & Violets are bundled.
- [ ] Each character has a name, team, ability text and night order positions.
- [ ] The Storyteller can choose a script when starting a new game.

## Notes / open questions
- Should Phase 1 ship all three scripts, or only Trouble Brewing first?
- Travellers and Fabled: are they in Phase 1?
