# R-010: Game history

**Phase:** 3 · **Priority:** Should · **Status:** Draft

## User story
As the Storyteller, I want finished games kept in a history so that I can look back at who played what and which team won.

## Acceptance criteria
- [ ] The Storyteller can end a game and record the winning team.
- [ ] Finished games move from saved games to history.
- [ ] A finished game can be reopened and edited, e.g. if it was ended by mistake. Recording a winner is optional.
- [ ] History shows date, script, players, characters and winner.
