# R-005: Multiple saved games

**Phase:** 1 · **Priority:** Must · **Status:** Draft

## User story
As the Storyteller, I want games saved automatically and listed so that I never lose state and can keep more than one game going.

## Acceptance criteria
- [ ] Every change is saved automatically. No manual save is needed.
- [ ] A game survives the app being killed, a phone restart and an app update.
- [ ] The saved games list shows script, player count, last-modified time and day/night.
- [ ] The Storyteller can resume, rename and delete a saved game.
