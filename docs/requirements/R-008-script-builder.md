# R-008: In-app script builder

**Phase:** 2 · **Priority:** Must · **Status:** Draft

## User story
As the Storyteller, I want to build my own scripts in the app from the bundled characters so that I can run games beyond the base scripts.

## Acceptance criteria
- [ ] The Storyteller can create, name, edit and delete custom scripts.
- [ ] Characters can be picked from the whole bundled character list, filtered by team and edition.
- [ ] The builder shows how many characters of each team the script has. Unusual counts (e.g. no Demon) are highlighted, never blocked.
- [ ] Custom scripts appear next to the default scripts at game setup.

## Notes / open questions
- Should the builder support homebrew characters, or only official ones?
- Should it show jinxes?
