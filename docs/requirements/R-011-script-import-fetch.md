# R-011: Script import and fetch

**Phase:** Later · **Priority:** Could · **Status:** Draft

## User story
As the Storyteller, I want to import scripts made in the official Script Tool, or fetch them from online sources, so that I don't have to rebuild them by hand.

## Acceptance criteria
- [ ] Import from a script JSON file or from pasted JSON in the official format.
- [ ] Fetch a script from a URL when online.
- [ ] Unknown characters are reported, not silently dropped.
