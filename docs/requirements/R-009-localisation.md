# R-009: English, Russian, Swedish

**Phase:** 3 · **Priority:** Must · **Status:** Draft

## User story
As the Storyteller, I want to use the app and the character text in English, Russian or Swedish so that I can run games for groups who speak those languages.

## Acceptance criteria
- [ ] The UI is translated into en, ru and sv.
- [ ] Character names, abilities and reminder texts are translated into en, ru and sv.
- [ ] The language follows the device setting and can be changed in the app.
- [ ] Strings are externalised from Phase 1, so Phase 3 only adds translations.

## Notes / open questions
- Should the UI language and the character text language be set separately?
