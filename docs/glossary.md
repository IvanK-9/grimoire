# Glossary

| Term | Meaning |
|---|---|
| **Storyteller** | The game master who runs the game. The primary user of this app. |
| **Grimoire** | The Storyteller's private view of the game: every seat, character, state and reminder. |
| **Script** | The set of characters available in a game. |
| **Default script** | A script bundled with the app, e.g. Trouble Brewing, Bad Moon Rising, Sects & Violets. |
| **Custom script** | A script the Storyteller builds in the app, or imports later. |
| **Edition** | An official character set (the three base editions, Experimental). |
| **Character** | A role with an ability, belonging to one team. |
| **Team** | Townsfolk, Outsider (Good); Minion, Demon (Evil); Traveller; Fabled. |
| **Seat** | One position around the table, held by one player. |
| **Player count** | The number of non-Traveller players (5–15). It determines how many characters of each team are in play. |
| **Setup modifier** | An ability that changes the team counts at setup, e.g. Baron [+2 Outsiders]. |
| **Alive / dead** | Player state. Dead players can still talk and keep one ghost vote. |
| **Ghost vote** | The single vote a dead player may use once for the rest of the game. |
| **Reminder token** | A marker placed on a seat to track an ability's effect, e.g. "Poisoned", "Drunk". |
| **Night order** | The order in which characters wake during the first night and other nights. |
| **Saved game** | A game stored on the device that can be resumed. |
| **Game history** | A record of finished games. |
